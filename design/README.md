## 一句话项目目标

为"校墙"留言板网站新增一个**独立、可插拔的认证安全模块**：以学校邮箱为注册门槛、指纹（WebAuthn/通行证）为日常登录手段、静态恢复码作为丢失设备后的兜底，并用"不开启 MFA 就不能发帖"的门槛引导全校师生自愿升级。

## 全局已定约束（贯穿所有 Part）

1. **校园环境**：注册仅限学校邮箱域；手机号仅在注册时验证一次，此后绝不用于登录（学生校内不便使用手机）。
2. **日常体验**：学生配备带 Touch ID 的专用 MacBook → 采用 WebAuthn 通行证（指纹）作为**最高等级、首选兼底线**的验证手段（对齐 Google 的 Passkey 定位）；常态下"只刷指纹即可登录"，密码降格为无指纹设备时的**兜底通道**。风控判为可疑时不反问密码，而是叠加独立核验手段。
3. **引导策略**（类 Steam）：未启用 MFA 的账号只能浏览，不能发帖、回复等互动。
4. **恢复策略**：静态一次性恢复码，覆盖换机、设备丢失、盗号。
5. **工程环境**：无构建工具的纯静态站 + Supabase BaaS；新模块必须以低侵入方式挂载。
